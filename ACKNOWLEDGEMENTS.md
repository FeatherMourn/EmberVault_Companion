# Acknowledgements

EmberVault Companion builds on the work of the Enshrouded modding community.
This page recognizes the upstream projects that inform the EML and ShroudForge
integration work. EmberVault Companion is an independent project and is not
owned, endorsed, or officially affiliated with either project.

## EML and KFC Parser

We acknowledge **Brabb3l** and the contributors to the
[KFC Parser and Enshrouded Mod Loader project](https://github.com/Brabb3l/kfc-parser).
That project provides the EML ecosystem, KFC parsing tools, resource and
reflection documentation, and related modding infrastructure that inform the
EML 2.0 roadmap.

The repository currently identifies its project license as
[GNU General Public License v3.0](https://github.com/Brabb3l/kfc-parser/blob/main/LICENSE),
not MIT. Any code reuse, redistribution, or derivative work must follow the
upstream license and applicable notices. EmberVault Companion primarily uses
the project as a documented integration reference unless code is explicitly
identified and carried forward under the required license terms.

## ShroudForge

We acknowledge **bonsaibauer** and the contributors to the
[ShroudForge project](https://github.com/bonsaibauer/shroudforge). ShroudForge
provides the Enshrouded mod runtime, Modloader, module lifecycle, and creator
documentation that inform the ShroudForge runtime roadmap.

ShroudForge is published under the
[MIT License](https://github.com/bonsaibauer/shroudforge/blob/main/LICENSE).
Any included or adapted source remains subject to that license and its notice
requirements.

## Attribution principles

- Keep upstream names, links, licenses, and notices with any reused material.
- Clearly distinguish upstream code from EmberVault Companion code.
- Do not imply endorsement or official affiliation.
- Record the upstream commit or release when incorporating source material.
- Keep generated mappings, probe evidence, and original EmberVault tooling
  documented separately from upstream projects.

If an upstream license, ownership record, or attribution requirement changes,
update this page before distributing a new Companion release.
